# カロリー収支（PWA）

安静時消費・アクティブエネルギーと、「型」の食事＋追加の摂取から、日々のカロリー収支を追いかける道具です。体重を記録すると、収支からの予測と実測を突き合わせて補正係数を推定します。

データは各自の端末（ブラウザ内）にだけ保存され、サーバーには送られません。

---

## 1. 公開する（GitHub Pages）

PWAは https で配信する必要があります。GitHub Pages なら無料で済みます。

1. GitHub で新しいリポジトリを作る（例：`calbal`。公開リポジトリでOK。データはコードに含まれません）
2. このフォルダの中身（`index.html` / `manifest.webmanifest` / `sw.js` / `icons/`）をそのままアップロード
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/calbal/` で開けます

Mac のターミナルからなら：

```sh
cd calbal
git init && git add . && git commit -m "first"
gh repo create calbal --public --source=. --push
gh api -X POST repos/{owner}/calbal/pages -f "source[branch]=main" -f "source[path]=/"
```

更新するときは、ファイルを差し替えて push するだけです。

## 2. iPhone のホーム画面に追加する

1. Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はホーム画面のアイコンから開く

**注意：** iPhone では、ホーム画面から開いたアプリと Safari で開いたページは**保存領域が別**です。記録は必ずホーム画面のアイコンから行ってください（Safari 側で入力したデータはアプリ側に出てきません）。

## 3. 使い方

- **記録する**：日付ごとに安静時・アクティブ・体重を入力。型の食事はチェックの ON/OFF と kcal の微調整、おやつなどは「追加の摂取」に。よく使う追加分はチップで一発入力できます。
- **推移**：体重の実測・7日平均・「収支からの予測」を重ねたグラフと、補正係数の推定。
- **設定**：食事の型、1kgあたりのkcal（既定 7,200）、安静時の既定値、補正係数、バックアップ。

補正係数は、体重（週3回以上）と消費の記録が2〜4週間ほどたまると推定できます。「記録上の平均消費」と「体重の変化から逆算した実際の消費」の比です。

## 4. ヘルスケアからの取り込み（ショートカット）

ショートカットで次の形式のテキストをクリップボードにコピーし、アプリ右上の「📋 取り込み」を押すと、その日の記録に入ります。

```
CALBAL date=2026-09-27 rest=1620 active=480 weight=60.0
```

- 項目は一部だけでもOK（例：`rest` だけ）
- `date` は `yyyy-MM-dd`、または `today` / `yesterday`。省略すると画面に表示中の日付に入ります
- クリップボードを読めない場合は、貼り付け欄が開くので長押しで貼り付けてください

その日のヘルスケアの値は一日が終わるまで増え続けるので、**翌朝に「昨日」の分を取り込む**運用がおすすめです。

### 4-1. Apple Watch の人（すべてヘルスケアから）

ショートカットアプリで新規作成し、次のアクションを順に並べます。

1. **日付**（現在の日付）→ **日付を調整**：1日を減算 → 変数名「昨日」
2. **日付をフォーマット**：「昨日」をカスタム形式 `yyyy-MM-dd` に → 変数名「日付文字列」
3. **ヘルスケアサンプルを検索**：種類＝安静時消費エネルギー、開始日＝「昨日」（その日のサンプルに絞る）
4. **統計を計算**：合計 → **数値を丸める** → 変数名「安静時」
5. 3〜4 と同じ手順で、種類＝アクティブエネルギー → 変数名「アクティブ」
6. （体重計がヘルスケアに記録している場合）**ヘルスケアサンプルを検索**：種類＝体重、並べ替え＝開始日（新しい順）、制限＝1 → 変数名「体重」
7. **テキスト**：`CALBAL date=[日付文字列] rest=[安静時] active=[アクティブ] weight=[体重]`
8. **クリップボードにコピー**
9. （任意）**通知を表示**：「コピーしました。アプリで取り込みを押してください」

アクション名や絞り込み項目の表記は iOS のバージョンで少し違うことがあります。最初は手順 7 の後に「結果を表示」を挟んで、数値が正しいか確認してください。

「オートメーション」タブで「時刻：毎朝7:00 → このショートカットを実行（すぐに実行）」にしておくと、朝アプリを開いて「取り込み」を押すだけになります。

### 4-2. Apple Watch 以外のWatchの人（アクティブは手入力）

上の手順から、アクティブエネルギーの部分を次に差し替えます。

- **入力を要求**：数値、質問文「昨日のアクティブエネルギー（Watchアプリの値）」→ 変数名「アクティブ」

もしくは、ショートカットは安静時だけにして、アクティブはアプリの画面で直接入力しても構いません。

安静時消費がヘルスケアに入っていない日がある場合は、「設定 → 安静時消費の既定値」に普段の値を入れておくと、未入力の日はその値で計算します（画面に「既定値」と表示されます）。

## 5. バックアップ

「設定 → 書き出し」で JSON ファイルを保存できます。機種変更や万一に備えて、ときどき書き出してファイルアプリやiCloud Driveに置いておいてください。「ファイルから復元」で戻せます。

## ファイル構成

```
index.html              アプリ本体（HTML/CSS/JS 一枚）
manifest.webmanifest    ホーム画面追加用の設定
sw.js                   オフライン用（ネットワーク優先＋キャッシュ）
icons/                  アイコン
```
